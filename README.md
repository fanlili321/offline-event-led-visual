# 线下活动超宽屏主视觉 Skill

按已确认的“样式2”模板，为银行螺丝钉线下活动生成高净值场和大众场主视觉。模板原图随仓库提供；生成时只替换城市与日期，保留标题、Logo、装饰和版式。

## 安装

将仓库克隆或复制到 `~/.codex/skills/offline-event-led-visual`，重新开始一个 Codex 任务后即可使用。也可以在对话中明确指定 `$offline-event-led-visual`。

## 提供的信息

- 城市，例如“长沙”
- 活动日期，例如“2026-11-01”；星期可由日期计算
- 活动时间，用于核对；默认不显示在图上
- 屏幕宽高比或像素尺寸，例如 `48:17` 或 `3024×1071`
- 可选：定稿的 16:9 PDF；只有要求完整播放文件时才需提供

## 示例

> 使用 `$offline-event-led-visual`，生成长沙站高净值场和大众场主视觉。日期是 2026 年 11 月 1 日，活动时间分别是上午和下午，现场屏幕比例为 48:17。请输出封面、目录和正文图片。

## 输出与核查

默认输出两类场次各自的封面、目录和正文主视觉图片。提供定稿 PDF 且要求合成时，另输出逐页适配的超宽 PDF。右侧日期须水平居中；不在两侧新增二维码；原 PDF 页面及其已有二维码保持不变。交付前检查旧城市、旧日期无残留，文字清晰，边框和装饰完整，页面比例与现场屏幕一致。

## 模板授权

`assets/` 中的图片来自项目内部已确认的活动样式。使用、再分发和公开仓库权限应由素材权利人确认。
